# Resources and References

- [Behave Documentation (stable)](https://behave.readthedocs.io/en/stable/) -- Official docs for the current stable release (1.3.3)
- [Behave Documentation (latest)](https://behave.readthedocs.io/en/latest/) -- Development docs for upcoming features
- [Behave Tutorial](https://behave.readthedocs.io/en/stable/tutorial/) -- Step-by-step getting started guide
- [Behave API Reference](https://behave.readthedocs.io/en/stable/api/) -- Complete API documentation
- [Behave GitHub Repository](https://github.com/behave/behave) -- Source code and issue tracker

- [Behave Examples](https://jenisys.github.io/behave.example/) -- Worked examples covering step matchers, data types, and patterns
- [parse Library](https://pypi.org/project/parse/) -- Format-based string parsing used by behave's default step matcher

- [Allure Behave Integration](https://allurereport.org/docs/behave/) -- Rich test reporting for behave
- [BehaveX](https://pypi.org/project/behavex/) -- Parallel execution wrapper for behave
- [behave-html-pretty-formatter](https://pypi.org/project/behave-html-pretty-formatter/) -- Actively maintained HTML report generator
- [Behave on PyPI](https://pypi.org/project/behave/) -- Package information and version history
